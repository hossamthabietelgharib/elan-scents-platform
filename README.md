# Élan Scents

**THE HOME OF GULF FRAGRANCES**

منصة عطور خليجية أوريجنال فاخرة.

## الملفات

- `index.html` — الهيكل الكامل
- `styles.css` — الهوية البصرية (ذهب 3D، كروت بارزة)
- `app.js` — التفاعلات والبيانات التجريبية

## التشغيل

افتح `index.html` في المتصفح مباشرة.

أو فعّل GitHub Pages من Settings → Pages → Source: Deploy from branch `main`.
